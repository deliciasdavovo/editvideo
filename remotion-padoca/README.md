# Delícias da Vovó — Remotion

Projeto isolado para não alterar o editor existente.

## Rodar

```bash
cd remotion-padoca
npm install
npm run studio
npm run render
```

## Fotos necessárias

Coloque em `public/` as fotos originais do Google Drive, com os nomes `croissant.jpg`, `trouxinha.jpg`, `mesa.jpg`.

Esta é uma **base editável**, não o vídeo final. A composição tem 25 segundos, formato 1080×1920, 30 fps. A trilha sonora ainda precisa ser escolhida/adicionada. A proposta visual deve ser revisada com fotos mais variadas da rotina real antes da publicação.
